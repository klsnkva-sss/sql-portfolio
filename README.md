# Анализ продаж

Я взяла данные о продажах компании и посмотрела, что там происходит. Данные сгенерированы ИИ.

## Что за данные и с чем работала

База `project1` содержит 6 таблиц:
- customers - клиенты
- products - товары
- sales - продажи
- suppliers - поставщики
- employees - сотрудники
- projects - проекты

## Анализ

### 1. Топ-5 товаров по выручке

Соединила товары и продажи, посчитала выручку по каждому товару и вывела 5 с самой высокой выручкой.

Получилось:
| Товар | Выручка |
|-------|---------|
| DGX Station | 49 999,99 |
| Tesla V100 | 26 999,97 |
| GeForce RTX 4090 | 25 599,84 |
| Quadro RTX 6000 | 19 999,95 |
| GeForce RTX 4070 | 19 199,68 |

Вывод: DGX Station - на первом месте. Он дорогой, поэтому даёт много выручки.

### 2. Продажи по регионам

Посчитала, сколько единиц товара продано в каждом регионе.

| Регион | Количество |
|--------|------------|
| Europe | 128 |
| North America | 18 |

Европа - основной рынок. Там 88% всех продаж.

### 3. Топ-5 клиентов по тратам

Посмотрела, кто из клиентов потратил больше всего и вывела 5 с наибольшей выручкой.

| Клиент | Потратил |
|--------|----------|
| SoftWorks | 49 999,99 |
| GreenEnergy | 25 999,96 |
| Tech Corp | 24 399,83 |
| MedPlus | 21 599,74 |
| EduWorld | 20 999,96 |

SoftWorks потратил больше всех - почти 50 тысяч.

### 4. Средний чек по регионам

Посчитала среднюю стоимость покупки в каждом регионе.

| Регион | Средний чек |
|--------|-------------|
| North America | 24 799,94 |
| Europe | 8 983,23 |

В Северной Америке средний чек выше - почти 25 тысяч против 9 тысяч в Европе.

### 5. Доля категорий

Посчитала, какую долю в общей выручке даёт каждая категория товаров.

| Категория | Доля |
|-----------|------|
| AI | 42,26% |
| GPU | 32,49% |
| Professional | 20,86% |
| Embedded | 2,74% |
| Consumer | 1,65% |

AI и GPU вместе дают 74% выручки. Остальные три категории - только 26%.

### 6. Клиенты без покупок

Искала клиентов, которые ничего не купили. Не нашла - все клиенты что-то покупали.

### 7. Товары без продаж

Искала товары, которые ни разу не продались. Не нашла - все товары продавались.

### 8. Продажи по месяцам

Посмотрела, сколько единиц товара продано в каждом месяце.

| Месяц | Количество |
|-------|------------|
| 1 | 15 |
| 2 | 25 |
| 3 | 78 |
| 4 | 28 |

Пик продаж - в марте. В апреле продажи упали.
